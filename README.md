# BMI Calculator using Python

## Introduction
This project is a simple BMI (Body Mass Index) calculator developed using Python.

## Objective
To calculate a person's BMI using their weight and height.

## Formula
BMI = Weight (kg) / Height² (m²)

## Requirements
- Python 3.x
- No external libraries are required.

## How to Run
1. Install Python.
2. Open the project folder.
3. Run the following command:

python bmi_calculator.py

4. Enter your weight and height when asked.

## Example
Enter your weight in kg: 60
Enter your height in meters: 1.65

Your BMI is: 22.04
Category: Normal weight

## Features
- Simple and easy to use
- Calculates BMI automatically
- Displays BMI category

## Conclusion
This project demonstrates the use of Python variables, user input, mathematical calculations, and conditional statements.
